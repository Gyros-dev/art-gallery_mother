# Как управлять сайтом

Сайт наполняется через **панель управления** — обычные формы, без файлов и кода.
Это основной и рекомендуемый способ. Ручная загрузка файлов описана в конце
как запасной путь.

Адрес сайта: **https://annaveksler.ru**

---

# Панель управления

Адрес: **app.pagescms.org** → войти через GitHub → выбрать «art-gallery_mother».

| Раздел | Что в нём |
|---|---|
| **Работы — Гобелен** | Карточки работ: название, картинки, материалы, размер, год |
| **Работы — Коллаж** | То же для коллажей |
| **Работы — Арт-объект** | То же для арт-объектов |
| **Выставки** | Название, даты, место, фотографии |
| **Публикации и статьи** | Тексты для раздела «Литература» |
| **Настройки сайта** | Название, домен, контакты, «Избранное» на главной |

Отдельно в разделе **Media** лежат сами файлы картинок по папкам. Обычно туда
заходить не нужно — картинку проще загрузить прямо из карточки работы. Media
нужна в двух случаях: создать папку для фотографий с выставки и **окончательно
удалить картинку** с сайта.

После «Save» сайт пересобирается сам и обновляется за 1–2 минуты.
**Предпросмотр** — просто откройте https://annaveksler.ru через пару минут:
там будет ровно то, что получилось.

> **Поломка не попадёт на сайт.** Сборка проверяет данные. Если что-то не так,
> публикации не будет — останется прежняя рабочая версия, а на почту придёт
> письмо от GitHub с описанием проблемы.

# 1. Добавить работу

**Работы — Гобелен** (или Коллаж / Арт-объект) → кнопка **«+»**.

| Поле | Что писать |
|---|---|
| **Название работы** | Так работа подписана на сайте |
| **Изображения** | Кнопка загрузки. Можно перетащить файл с компьютера |
| **Материалы** | Отметить галочками в списке |
| **Другие материалы** | Только если нужного нет в списке — вписать через запятую |
| **Размер** | Например `100х150 см` |
| **Год** | Например `2024` |
| **Расположение частей** | Только для серии, см. ниже |
| **Номер в категории** | Обычно не нужен, см. ниже |

Нажать **Save**. Через 1–2 минуты работа на сайте.

### Про картинки
Грузите **самый большой и качественный файл, какой есть** — jpg, png или webp.
Сайт сам сделает из него три размера:

- маленький эскиз для сетки,
- средний для страницы галереи,
- **оригинал во всю величину — он открывается, когда работу разворачивают
  на весь экран.**

Ужимать и подгонять ничего не надо, размер на сайте подстраивается сам.

### Про материалы
Список уже заполнен теми материалами, что есть на сайте: шерсть, вискоза,
ручное ткачество, текстиль, бумага, медь, гор. эмаль, стекло.
Отмечайте нужные галочками — они встанут в описание через запятую.

Нужного материала нет в списке? Впишите его в соседнее поле
**«Другие материалы»** обычным текстом, через запятую: `лён, металлическая нить`.
Он добавится в подпись после тех, что отмечены галочками.

# 2. Изменить, заменить или удалить

### Изменить работу
«Работы — <категория>» → щёлкнуть по работе в списке → поправить → **Save**.
Название можно менять в любой момент, картинка при этом не потеряется.

### Заменить или добавить картинку
В карточке, в поле «Изображения»: навести на ненужную картинку → **крестик**,
затем загрузить новую. Порядок картинок меняется перетаскиванием мышкой.

### Поменять местами части серии
Просто перетащите картинки внутри поля «Изображения». Как расставите — так
и будет на сайте.

### Удалить работу с сайта
Это **два шага**, и второй обязателен:

1. Открыть карточку работы → меню с тремя точками вверху справа → **Delete**.
2. Зайти в **Media → «Картинки — <категория>»** и удалить там саму картинку.

Если сделать только первый шаг, работа вернётся на сайт — но уже без описания,
с названием по имени файла. Так задумано: картинка в папке всегда попадает
в галерею, даже если карточку кто-то случайно удалил.

### Удалить выставку или статью
Открыть → меню с тремя точками → **Delete**. Здесь одного шага достаточно.

# 3. Серия работ (диптих, триптих, несколько связанных)

Серия — это **одна карточка с несколькими картинками**.

1. Создайте карточку как обычно.
2. В поле «Изображения» загрузите все части.
3. **Порядок** — перетаскиванием прямо в списке. Как расставите, так и будет
   на сайте.
4. **Расположение частей** — выпадающий список:

| Выбор | Что получится |
|---|---|
| **Автоматически** | Сайт решит сам: до трёх частей и вытянутые вверх — в ряд, остальные — квадратом |
| **В ряд  ▭ ▭ ▭** | Все части в одну линию |
| **Квадратом  ▭ ▭ / ▭ ▭** | Части сеткой 2×2, 3×3… |

**Размеры у частей разные?** Перечислите через запятую в поле «Размер»:
`15х30 см, 25х25 см, 20х42 см`.

**Подписи частей** («Матфей», «Марк») берутся из имён файлов. Хотите подписи —
назовите файлы `1. Матфей.jpg`, `2. Марк.jpg` перед загрузкой. Не хотите —
покажется просто «1/4», «2/4».

---

# 4. Порядок работ в категории

По умолчанию работы идут по алфавиту. Это менять не обязательно.

Хотите вынести работу вперёд — впишите **«Номер в категории»**: `1`, `2`, `3`.
Работы с номерами встают в начало по возрастанию, все остальные — за ними,
как обычно. У работ без номера ничего не меняется.

# 5. Выставки

Раздел **«Выставки»** → «+».

| Поле | Пример |
|---|---|
| Название | `Пятая Петербургская биеннале` |
| Даты | `07 августа — 18 октября 2026` или просто `2024` |
| Место | `Манеж, Исаакиевская пл. 1, Санкт-Петербург` |
| Описание | Необязательно |
| Сайт выставки | Только адрес, начинающийся с `https://` |
| Папка с фотографиями | Название папки, см. ниже |

**Статус выставки считается сам — по дате.** Ничего переключать не нужно:
идёт сейчас → бейдж «Идёт сейчас» и место вверху страницы; ещё не началась →
«Скоро»; закончилась → уезжает в «Архив».

### Фотографии с выставки
1. В разделе **Media → «Фотографии с выставок»** создайте папку и загрузите фото.
2. В карточке выставки впишите название этой папки в поле «Папка с фотографиями».

На странице появятся миниатюры и кнопка «Фотографии».

# 6. Настройки сайта

Раздел **«Настройки сайта»** — название, описание для поисковиков, адрес,
город, контакты и «Избранное».

- **Фотография художника** — снимок на странице «Художник». Нажать на поле →
  **Upload** → выбрать файл (можно перетащить мышкой). Подойдёт фотография
  **любого размера и формата**: сайт сам впишет её в рамку, вёрстка не поедет.
  Лучше всего смотрится вертикальный или квадратный снимок; широкий будет
  аккуратно подрезан по бокам.
- **Почта и телефон.** Пусто = контакт просто не показывается на сайте.
- **Соцсети.** Пустая ссылка = кнопки нет.
- **«Избранное на главной»** — названия работ в нужном порядке; они крутятся
  в карусели на главной. **Первая работа из списка становится картинкой-превью**,
  которую видят люди, когда вы отправляете ссылку на сайт в мессенджере.
  Оставите пустым — покажутся 6 случайных.

---

# 7. Публикации

Раздел **«Публикации и статьи»** → «+».
Первая строка текста = заголовок, дальше сам текст. Появится в «Литературе».

**PDF-пособие** кладётся в папку `docs/`, и на него добавляется строка на
странице `pages/literature.html` — это уже ручная правка.

# Запасной способ: файлы напрямую

Панель управления — просто удобная обёртка над файлами репозитория. Всё то же
самое можно сделать руками, и старый порядок продолжает работать.

- **Через сайт GitHub:** открыть нужную папку на github.com → «Add file» →
  «Upload files» → перетащить → «Commit changes».
- **С компьютера:** положить файлы в папки проекта и выполнить
  `git add -A && git commit -m "новые работы" && git push`.

Как это устроено:

| Что | Где лежит |
|---|---|
| Картинки работ | `images/art/Гобелен`, `Коллаж`, `Арт-объект` |
| Карточка работы (название, материалы, размер, год, порядок) | `content/works/<Категория>/<Название>.md` |
| Выставки | `data/exhibitions.json` |
| Фото с выставок | `images/exhibitions/<имя папки из карточки выставки>` |
| Статьи | `content/texts` |
| Название сайта, домен, контакты, «Избранное» | `data/site.json` |

**Картинка без карточки тоже попадёт на сайт** — название возьмётся из имени
файла, а подпапка внутри категории станет серией. Карточка нужна, чтобы задать
материалы, размер, год, порядок частей и раскладку.

**Новая категория** — новая папка в `images/art`, например `images/art/Живопись`.
На сайте появится новый фильтр. Чтобы категория появилась и в панели управления,
нужно добавить её в файл `.pages.yml` — это правка на десять строк, по образцу
соседних категорий.

# Коротко

| Что нужно | Что сделать в панели |

| Фото с выставки | Media → «Фотографии с выставок» → папка |

| Фото художника | «Настройки сайта» → «Фотография художника» |
