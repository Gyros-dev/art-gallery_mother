# Как управлять сайтом

Сайт наполняется **раскладкой файлов по папкам**. Никакого программирования.
Положили файл в нужную папку → через 1–2 минуты он на сайте.

## Два способа загрузить файлы

- **Через сайт GitHub** (проще всего, ничего устанавливать не нужно):
  открываете нужную папку на github.com → «Add file» → «Upload files» →
  перетаскиваете → «Commit changes». Готово.
- **С компьютера:** кладёте файлы в папки проекта и выполняете
  `git add -A && git commit -m "новые работы" && git push`.

После загрузки сайт пересобирается сам. **Картинки тоже обрабатываются сами:**
можно смело грузить тяжёлые фото в высоком качестве — их ужмут до нужного
размера и сделают эскизы для сетки. Ничего пережимать вручную не надо.

> **Если что-то пошло не так.** Сборка проверяет данные и, если найдёт ошибку
> (например, пропущенную запятую в настройках), **не публикует поломку** —
> на сайте останется прежняя рабочая версия, а вам на почту придёт письмо от
> GitHub с описанием проблемы.

# 1. Работы в галерее

Категории — это папки внутри `images/art`. Сейчас их три:

```
images/art/Гобелен/
images/art/Коллаж/
images/art/Арт-объект/
```

### Добавить одну работу
Положите картинку в папку категории. **Название работы = имя файла.**

```
images/art/Гобелен/Ангел.jpg      →  работа «Ангел»
```

### Добавить описание к работе
Рядом положите текстовый файл **с тем же именем**:

```
images/art/Гобелен/Ангел.txt
```
внутри одна строка:
```
Шерсть, ручное ткачество, 60 × 80 см, 2016
```
Текст покажется под работой и при увеличении.

### Добавить серию (диптих, триптих, несколько связанных работ)
Создайте **подпапку** — её имя станет названием серии:

```
images/art/Гобелен/Евангелисты/
    1. Матфей.jpg
    2. Марк.jpg
    3. Лука.jpg
    4. Иоанн.jpg
    _info.txt          ← описание всей серии (необязательно)
```

- **Порядок частей** задаёт число в начале имени файла.
- **Подпись части** — то, что идёт после числа («Матфей», «Марк»…).
  Не нужна подпись? Называйте файлы `Название серии - 1.jpg`, `- 2.jpg` —
  тогда покажется просто «1/4», «2/4».
- **Описание одной части** — файл с тем же именем: `1. Матфей.txt`.

### Как расположить части: квадратом или в ряд
Обычно сайт решает сам: вытянутые вертикально работы ставит в ряд,
квадратные и горизонтальные (если их 4 и больше) — квадратом.

Хотите задать вручную — положите в папку серии файл `_layout.txt`
с одним словом внутри:

```
квадрат      →  части встанут сеткой (2×2, 3×3 …)
ряд          →  части встанут в одну линию
```

### Добавить новую категорию
Просто создайте новую папку в `images/art`, например `images/art/Живопись`,
и кладите туда работы. На сайте появится новый фильтр «Живопись».

# 2. Выставки

Файл `data/exhibitions.json`. Каждая выставка — блок в фигурных скобках.
Чтобы добавить новую, **скопируйте существующий блок** и поменяйте текст:

```json
  {
    "title": "Название выставки",
    "date": "07 августа — 18 октября 2026",
    "location": "Название зала, улица, город",
    "description": "Короткое пояснение (можно оставить пустым)",
    "url": "https://сайт-выставки.ру",
    "photos": "Название папки с фото"
  },
```

**Важно про даты.** Сайт сам определяет, выставка уже прошла, идёт сейчас или
только будет — **по дате**. Ничего переключать вручную не нужно. Пишите дату
привычно: `«07 августа — 18 октября 2026»` или просто `«2024»`.

- Идёт прямо сейчас → бейдж «Идёт сейчас», выставка вверху страницы
- Ещё не началась → бейдж «Скоро»
- Закончилась → уезжает в «Архив»

**Поля `url`, `description` и `photos` можно не заполнять** — оставьте пустые
кавычки `""` или уберите строку целиком.

### Фотографии с выставки
1. В блоке выставки в поле `"photos"` напишите название папки.
2. Создайте папку `images/exhibitions/<это же название>` и положите туда фото.

На странице появятся миниатюры и кнопка «Фотографии».

> ⚠️ В этом файле важны **запятые и кавычки**. После каждого блока, кроме
> последнего, стоит запятая. Если ошибётесь — сборка не опубликует поломку и
> пришлёт письмо с подсказкой.

# 3. Настройки сайта

Файл `data/site.json` — там название, адрес, контакты и «Избранное».
Меняйте только текст **справа от двоеточия**, внутри кавычек.

| Что | Поле |
|---|---|
| Название сайта (видно во вкладке браузера и при отправке ссылки) | `title` |
| Короткое описание для поисковиков | `description` |
| **Адрес сайта** — когда купите домен, впишите сюда | `url` |
| Почта и телефон (пусто = не показываются) | `email`, `phone` |
| Ссылки на соцсети (пусто = кнопки нет) | `socials` |
| Какие работы показать на главной | `featured` |

### «Избранное» на главной
Перечислите названия работ (как имена файлов) в нужном порядке:

```json
  "featured": [
    "Река времени",
    "Евангелисты",
    "Птица-ночь"
  ]
```
Регистр букв и «ё/е» не важны. Оставите пустым `[]` — покажутся 6 случайных.
**Первая работа из списка становится картинкой-превью**, которую видят люди,
когда вы отправляете ссылку на сайт в мессенджере.

# 4. Тексты и публикации

- **Статья или эссе** → положите файл `.txt` или `.md` в папку `content/texts`.
  Первая строка = заголовок, дальше текст. Появится в разделе «Литература».
- **PDF-пособие** → положите файл в папку `docs/` и добавьте строку в список
  на странице `pages/literature.html`.

---

# 5. Когда купите домен

1. В `data/site.json` впишите новый адрес в поле `url`, например
   `"url": "https://annaveksler.ru"`.
2. В настройках репозитория на GitHub: **Settings → Pages → Custom domain** —
   укажите домен и включите **Enforce HTTPS**.
3. У регистратора домена добавьте записи, которые покажет GitHub.

Всё остальное (адреса страниц, карта сайта для поисковиков, превью для
мессенджеров) подстроится само.

# Коротко

| Что нужно | Куда положить |
|---|---|
| Работу | картинку в `images/art/Гобелен`, `Коллаж` или `Арт-объект` |
| Описание работы | `.txt` с тем же именем рядом с картинкой |
| Серию | подпапку с картинками внутри папки категории |
| Порядок и подписи частей серии | число в начале имени: `1. Матфей.jpg` |
| Расположение частей (квадрат/ряд) | файл `_layout.txt` в папке серии |
| Новую категорию | новую папку в `images/art` |
| Выставку | блок в `data/exhibitions.json` |
| Фото с выставки | картинки в `images/exhibitions/<имя из файла выставок>` |
| Статью | `.txt`/`.md` в `content/texts` |
| Название сайта, контакты, «Избранное», домен | `data/site.json` |
